# Índice de Documentación API

Esta carpeta contiene la documentación HTML generada automáticamente con pydoc para los módulos principales del proyecto.

## ¿Cómo consultar la documentación?

1. Abre cualquiera de los archivos `.html` con tu navegador web favorito.
2. Cada archivo corresponde a un módulo o componente del proyecto.

## Módulos documentados

- **Modelos:**
  - [bici.html](bici.html) — Clase Bici
  - [usuario.html](usuario.html) — Clase Usuario
  - [registro.html](registro.html) — Clase Registro
- **Gestión de datos:**
  - [csv_manager.html](csv_manager.html) — Funciones para manejo de CSV
- **Controladores:**
  - [parking_controller.html](parking_controller.html) — Fachada principal
  - [usuarios_controller.html](usuarios_controller.html) — Lógica de usuarios
  - [bicis_controller.html](bicis_controller.html) — Lógica de bicis
  - [movimientos_controller.html](movimientos_controller.html) — Lógica de entradas/salidas
- **Utilidades:**
  - [validaciones.html](validaciones.html) — Validación de DNI y email

## Notas
- La documentación se genera automáticamente a partir de los docstrings del código fuente.
- Si modificas el código, vuelve a ejecutar pydoc para actualizar estos archivos.
